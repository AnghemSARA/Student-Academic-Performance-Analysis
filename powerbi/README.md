# Power BI Dashboard

This folder contains the Power BI dashboard created for the Student Academic Performance Analysis project.

The dashboard was built using Power BI Desktop and connected to the cleaned SQL Server view:

`dbo.vw_student_analysis`

## Dashboard Content

The dashboard includes:

- KPI cards for total students, average final grade, passed students, failed students, pass rate, and fail rate
- Pass vs Fail distribution
- Students by performance level
- Average final grade by study time
- Interactive slicers for school, gender, address, and performance level
